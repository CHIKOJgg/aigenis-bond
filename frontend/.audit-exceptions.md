## GHSA-qwww-vcr4-c8h2 — React Router RSC Mode CSRF Bypass

| Field | Value |
|-------|-------|
| **Packages** | `react-router@7.18.2`, `react-router-dom@7.18.2` |
| **Severity** | High |
| **Advisory** | https://github.com/advisories/GHSA-qwww-vcr4-c8h2 |
| **Affected range** | react-router >=7.12.0 <8.3.0 |
| **Fix version** | react-router-dom >=8.3.0 (not yet released) |

**Assessment: NOT EXPLOITABLE in this project.**

The vulnerability targets React Server Components (RSC) mode. This project is a client-side
SPA using `react-router-dom` v7 with `BrowserRouter`/`RouterProvider` — RSC mode is not
enabled or used anywhere in the codebase.

**Mitigation:**
- Upgrade to `react-router-dom@^8.3.0` when released.
- Downgrade to `7.11.0` is NOT an option (breaking changes, loss of features).

**Review date:** 2026-08-13 (weekly, to check for v8.3.0 release)
