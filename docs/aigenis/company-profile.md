## 3. Их боли (почему им нужен наш продукт)

1. **Аналитика облигаций отдана конкурентам.** В FAQ страницы «Россия в вашем
   портфеле» на вопрос «где следить за рынком»:
   > «Аналитика: ИК Айгенис (обзоры), moex.com, **cbonds.ru**, finam.ru, investing.com»

   Переводится просто: у Aigenis нет собственного аналитического движка по
   облигациям — единственный сегмент линейки без своего продукта. Клиентов
   (и их премиум-подписку) они отдают конкурентам.

2. **Премиум-аналитика продаётся без контента.** Подписка уже есть и
   продвигается («месяц бесплатно»), но подписчику нечего дать — новости и
   обзоры бесплатны везде.

3. **Модельные портфели облигаций — вручную.** ИК «Айгенис» собирает их в
   PDF без ML-обоснования.

4. **БПИФ и облигации в иностранной валюте — «в планах»** (по FAQ MOEX),
   хотя рынок уже есть.

5. **B2B-контур не готов.** «Приложение дорабатывается для юрлиц» — нет
   партнёрского API, виджета, webhook-интеграций.

## 5. Три стратегических сценария для презентации ЛПР

1. **B2C (aigenis invest):** «Премиум-аналитика» внутри приложения — карточка
   облигации со Score и вердиктом, Desk для продвинутых, алерты. То, что
   удерживает подписчика и даёт повод платить.
2. **B2B (корп. клиенты / эмитенты):** аналитика эмитентов, стресс-тесты,
   виджет для сайтов клиентов, API — закрывает «дорабатывается для юрлиц».
3. **ИК «Айгенис» (Москва):** аналитический движок для инвестсоветников —
   ML-обоснование модельных портфелей, скоринг, автоматизация еженедельной аналитики.
