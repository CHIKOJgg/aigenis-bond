## Способ интеграции

### Вариант A: REST API (рекомендуемый для MVP)
Bonds Engine разворачивается как отдельный микросервис внутри инфраструктуры Aigenis.
Angular-терминал обращается к нему через REST API.

```
Aigenis Terminal (Angular) ──HTTP──▶ Bonds Engine API (FastAPI)
                                          │
                                          ├── /api/v1/bonds       (список)
                                          ├── /api/v1/scores      (скоринг)
                                          ├── /api/v1/desk/*      (Desk)
                                          └── /api/v1/ml/predict  (ML)
```

**Плюсы:** Быстро (1-2 дня), не трогает сборку Angular
**Минусы:** Нужен отдельный сервис

### Вариант B: iframe-виджет (самый быстрый)
Готовый React-компонент `AigenisBondAnalyzer` (уже написан, см. ниже)
встраивается через iframe в любую страницу терминала.

**Плюсы:** 1 час на интеграцию, полная изоляция
**Минусы:** Ограниченная кастомизация

### Вариант C: White-label встройка (финальный)
Полная интеграция компонентов в кодовую базу Angular.
Используются те же CSS-переменные, шрифты, дизайн-токены.

## Что уже готово для интеграции

### 1. CSS-тема Aigenis (frontend/src/aigenis-theme.css)
Полный набор CSS-переменных, повторяющих дизайн-систему web.aigenis.by:
- Все цвета (бренд, текст, фон, бордеры, семантика)
- Шрифты (Montserrat + Onest)
- Радиусы, тени
- Компонентные стили (кнопки pill, карточки, таблицы, бейджи)
- Тир-бейджи S/A/B/C/D в цветах Aigenis

### 2. React-компонент AigenisBondAnalyzer (frontend/src/components/AigenisBondAnalyzer.tsx)
Полнофункциональный виджет в стиле Aigenis:
- Таблица облигаций с сортировкой и поиском
- Фильтр по валютам (ALL, USD, RUB, BYN, EUR, XAU, XAG, XPT)
- Колонки: название, Score (с тир-бейджем), YTM, купон, валюта, погашение
- Детальная карточка (модальное окно):
  - Тир-бейдж + вердикт + числовой Score
  - Разбор по 9 факторам в две колонки (зелёный/красный)
  - Таблица метрик (валюта, статус, YTM, купон, цена, номинал, эмитент)
  - Дисклеймер
- Пагинация, поиск по названию/ISIN/эмитенту
- Индикатор загрузки, обработка ошибок

### 3. Валидация данных (scoring/data_quality.py)
Система проверки качества данных перед скорингом:
- 9 типов проверок (свежесть, YTM bounds, цена/номинал, купон, статус)
- Три уровня: ok / warning / critical
- Critical-ошибки → облигация НЕ скорится (UNRATED)
- Warning → скоринг с понижающим коэффициентом 0.85
- Понятные сообщения на русском

### 4. Улучшенный скоринг (scoring/engine.py v2)
9-компонентная модель с расширенной классификацией эмитентов:
- 7 уровней кредитного риска
- Сглаженная дюрация (сигмоида)
- Поддержка RUB, CNY
- Градуированная инфляция
- Компоненты купона и волатильности

## Ключевое преимущество для Aigenis

Их премиум-аналитика УЖЕ продаётся за деньги, но у них нет контента для неё.
Bonds Engine даёт этот контент:
- **Скоринг** — понятный ответ «какую облигацию купить»
- **Desk** — инструменты для продвинутых (кривая, стресс-тесты)
- **ML** — автоматические рекомендации
- **Валидация** — данные проверены, скоринг не врёт

Всё это уже готово к интеграции. Деплой — 1 день. Интеграция — 1 неделя.
