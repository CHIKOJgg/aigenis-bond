## 2. Что им нужно (их боли → наши модули)

### 2.1. Ключевой пробел: аналитику облигаций они отдают конкурентам
В FAQ страницы «Россия в вашем портфеле» на вопрос «где следить за рынком»:
> «Аналитика: ИК Айгенис (обзоры), moex.com, **cbonds.ru**, finam.ru, investing.com»

**Перевод:** у Aigenis нет аналитического продукта по облигациям — клиентов (и их
внимание, и их «премиум-подписку») они отправляют к cbonds/finam/investing.
Это единственный сегмент в их линейке, где нет собственного движка.

| Их потребность (факт с сайта) | Модуль Bonds Engine | Доказательство |

### 2.3. Три стратегических сценария использования (для презентации ЛПР)

1. **B2C (aigenis invest):** «Премиум-аналитика» внутри приложения: карточка
   облигации с Score и вердиктом, Desk-раздел для продвинутых, алерты —
   то, что удерживает подписчика и даёт повод платить.
2. **B2B (корп. клиенты / эмитенты):** аналитика эмитентов, стресс-тесты,
   виджет для сайтов клиентов, API для интеграций — закрывает
   «дорабатывается для юрлиц».
3. **ИК «Айгенис» (Москва):** аналитический движок для инвестсоветников:
   ML-обоснование модельных портфелей, скоринг для рекомендаций,
   автоматизация еженедельной аналитики.

**Никогда не говорить:** «продукт построен на вашем API/сайте» (это прямо

## 7. Демо под их контекст (30-минутный сценарий)

Подготовка: демо-инстанс, MOEX-данные, закладки на 3 раздела.

1. **Карточка облигации** (1 мин): открыть ОФЗ + корпоративный выпуск —
   Score, вердикт, факторы. «Ваш клиент в приложении видит котировку,
   здесь он видит, ПОЧЕМУ она интересна».
2. **Desk** (5 мин): кривая доходности по валютам, RV-сигналы,
   стресс-тест портфеля на 7 сценариев. «Ни у одного брокера РБ этого нет».
3. **Рекомендации/ML** (3 мин): топ-5 с учётом диверсификации эмитентов.
   «Обоснование для модельных портфелей ИК».
4. **Портфель** (3 мин): P&L FIFO, снапшоты, ребалансировка, Monte-Carlo.
   «Готовый раздел для вкладки Портфель».
5. **B2B** (3 мин): партнёрский ключ из публичной формы, виджет —
   «то, что вы можете продавать корпоративным клиентам завтра».
6. **Монетизация** (2 мин): премиум-тир, биллинг Stars/YooKassa, гейтинг.
   «Ваша премиум-аналитика получает контент без найма аналитиков».
7. **Техническая готовность** (3 мин): Docker compose, CI, тесты,
   мониторинг. «Не MVP — продакшн».

Финал: «Давайте я за неделю разверну это на вашем сервере — вы оцените
внутри своей инфраструктуры».
