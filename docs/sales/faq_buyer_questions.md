## Этап 1: Первое касание

### Что это за продукт?
Bonds Engine - production-ready платформа аналитики облигаций:
- Данные MOEX ISS (1500+ бумаг RUB + USD/EUR)
- Reward/Risk Score 0-100 с объяснениями (9 компонентов, тиры S/A/B/C/D)
- Fixed Income Desk (Nelson-Siegel, duration/convexity, stress-тесты)
- ML-рекомендации buy/hold/wait/avoid с walk-forward валидацией
- Биллинг (YooKassa + Telegram Stars), партнёрский API
- Telegram-бот (40+ команд), React SPA, SEO-страницы

### Почему я должен этим заинтересоваться?
1. **Экономия $130k+.** Build: $150-180k и 6-9 мес. Buy: $25-65k, эффект через неделю.
2. **Удержание аудитории.** Клиенты ищут аналитику облигаций у конкурентов (cbonds, finam). Bonds Engine возвращает внимание в вашу экосистему.
3. **Готовый актив, не MVP.** 300+ тестов, Docker, CI/CD, мониторинг. Код обкатан.

### Кто целевой покупатель?
1. **Брокеры/инвесткомпании** - встроенный Fixed Income Desk
2. **Финтех-платформы** - white-label под своим брендом
3. **Инвестсоветники** - ML-обоснование модельных портфелей

### Есть ли демо?
Да, публичный демо-инстанс с реальными данными MOEX. Без регистрации. 15 минут: карточка облигации -> скоринг -> Desk -> ML -> портфель -> биллинг.

## Этап 2: Демо / Презентация

### Откуда данные? Это легально?
Продукт использует **публичный API MOEX ISS** (Московская биржа, информационно-статистический сервер) - открытые данные, доступные без логина, с официальной документацией. Никакого парсинга закрытых страниц.

Для белорусского рынка (BYN) адаптер переводится на официальный партнёрский канал в рамках сделки.

### Сколько облигаций в базе?
1500+. RUB (TQCB), USD/EUR еврооблигации (TQOB), BYN. Плюс акции MOEX. Обновление каждые 4-6 часов.

### Как работает скоринг?
9-компонентная модель (0-100 баллов):
- **Доходность** YTM (до 40 баллов)
- **Валюта**: USD=20, XAU=16, XAG=12, XPT=9, BYN=4, RUB=3, CNY=3, EUR=0
- **Дюрация**: сглаженная сигмоида (не пороги) - бонус за короткие бумаги
- **Ликвидность**: цена + статус + близость к погашению + цена/номинал
- **Драгметаллы**: XAU=5, XAG=4, XPT=3
- **Кредитный риск**: 7 уровней (суверен=+10, дефолт=-35)
- **Инфляция**: градуированная поправка по валюте и YTM
- **Купонный доход**: премия за стабильный купон
- **Волатильность**: штраф за экстремальные параметры

+ Буквенный тир (S/A/B/C/D) + объяснение на русском.

### ML реально работает?
Да. GradientBoosting (scikit-learn), walk-forward CV (защита от look-ahead). Две модели:
1. Регрессор YTM
2. Классификатор buy/hold/wait/avoid
30+ признаков, версионирование артефактов.

### Что в Fixed Income Desk?
Профессиональные инструменты:
- Nelson-Siegel кривая доходности (scipy)
- Duration, Modified Duration, Convexity, DV01, Key Rate Duration
- Relative Value (z-score rich/cheap сигналы)
- Carry Trade (купоны минус фондирование)
- REPO с haircut по типу эмитента
- Z-spread, G-spread
- Stress-тесты (7 сценариев)
- Cash flow projections

### Как работает биллинг?
1. **YooKassa**: карты, СБП, Apple/Google Pay. Защита: проверка IP, перепроверка API, возврат полной суммы, webhook replay guard
2. **Telegram Stars**: идемпотентность (telegram_payment_charge_id)

Тиры: Free -> Pro (29 BYN/мес) -> Enterprise (99 BYN/мес). Gating 402 + рефералы + affiliate.

### Есть ли API?
REST API (FastAPI):
- JWT (HS256, bcrypt, refresh, Google OAuth)
- Rate limiting тир-зависимый
- Партнёрский API: ключи, webhooks (HMAC), embed-виджет
- SEO: рендеринг страниц + sitemap + Schema.org
- i18n: RU/EN/BE

### Telegram-бот
40+ команд: поиск, скоринг, алерты (цена/YTM/новые выпуски), портфель, подписки, админка. Inline-клавиатуры. Оплата Stars идемпотентная.

## Этап 3: Технический due diligence

### Стек технологий
- **Backend**: Python 3.12+, FastAPI, SQLAlchemy async, Alembic, Pydantic v2
- **ML**: scikit-learn, numpy, scipy
- **Frontend**: React 19, TypeScript, Vite 6, Tailwind 4, Recharts, PWA
- **Бот**: aiogram 3
- **Инфра**: Docker Compose (9 сервисов), PostgreSQL 16, Redis 7, Nginx
- **Мониторинг**: Prometheus, Grafana, Sentry, Loguru
- **CI/CD**: GitHub Actions

### Объём кода
~44,000 строк Python + ~15,000 строк TypeScript/React. 52 тестовых файла, 24 миграции, документация.

### Безопасность
- JWT HS256 + bcrypt паролей
- Fail-closed auth
- HMAC-вебхуки для внешних интеграций
- Rate limiting (Redis/in-memory)
- CSP, X-Frame-Options, X-Content-Type-Options
- SSRF защита (IP pinning + IPv6)
- Рефреш-токены с ротацией

### Как деплоить?
Docker Compose up -d. 9 сервисов поднимаются одной командой. Включает:
- API + бот + парсер + PostgreSQL + Redis + Nginx + Prometheus + Grafana
- Cloudflare Tunnel для внешнего доступа без белого IP
- Миграции Alembic при старте

### Что с поддержкой?
Три варианта сделки:
1. **$25k** - IP + документация (код, Docker, CI, docs)
2. **$45k** - IP + 3 мес поддержки (20ч/мес, hotfixes, адаптация) [рекомендуемый]
3. **$65k** - IP + full-time разработчик в штат на 3 мес

Дополнительно: white-label лицензия ($8-15k/год), модульный вариант (от $10k).

### Есть ли технический долг?
Нет критического. Код чистый (ruff), типизированный (mypy). 300+ тестов. 24 миграции в порядке. Мониторинг настроен.

## Этап 4: Юридические вопросы

### Кому принадлежит интеллектуальная собственность?
При покупке IP - все права переходят покупателю. Полный репозиторий с историей коммитов, CI/CD конфигурация, docker-образы, документация.

### Нужен ли NDA?
Да, до передачи кода. Подписывается до демонстрации архитектуры и data-room.

### Какие гарантии?
- 2 недели на приёмку (demo-checklist как акт)
- Платёж: 50% предоплата / 50% при передаче
- 3 месяца поддержки в тарифе $45k

### Лицензия на данные MOEX
MOEX ISS - публичный API. Информация распространяется бесплатно. Bonds Engine не нарушает условия использования биржи.
